# XimmerTools for Blender

![Blender Addon](https://img.shields.io/badge/Blender-Blender%20Source-blue)

XimmerTools is a collection of tools I have been making to streamline my personal workflow.

## ✨ Core Functionality

*   **ShapeKey Sets:** Tool for generating shapekey names for sets of shapekeys such as VRC Visemes, Universal Expressions, ARKit, SRanipal. With conversion from Universal Expressions to other supported shape sets.
*   **ShapeKey Grouping:** Shapekey groups (prefixed with `===`). This feature allows users to efficiently move, and sort shapekeys within established groups.
*   **Split Shapekey:** Tool for splitting a single shapekeys Left and Right halves.
*   **Cleanup & Optimization:** The `Remove Unused Shapekeys` operator automatically deletes shapekeys that do not contribute meaningfully to the mesh's deformation.

## 🔨 Installation Guide

1.  **Download:** Download the official release package by clicking the green Code button and selecting "Download Zip".
2.  **Installation:**
    *   Launch Blender.
    *   Navigate to `Edit > Preferences > Add-ons`.
    *   Click the 'Install' button (the down arrow icon) and select `Install from Disk...`. Select the downloaded `XimmerTools` `.zip` file.
    *   Enable the **Ximmer Tools** addon by activating its corresponding checkbox.
3.  **Usage:** All shapekey operators are accessible through the Shape Keys context menu.
